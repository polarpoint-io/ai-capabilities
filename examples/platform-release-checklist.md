# Example: Platform Release Checklist

**Goal:** Ship a platform release safely with clear gates.

## Input (from AGENTS.md)
- Workflow phases
- Quality gates
- Standards

## Output Checklist
- [ ] Scope + success criteria defined
- [ ] Risk assessment documented
- [ ] Release plan approved
- [ ] Rollback plan validated
- [ ] Change log drafted
- [ ] SLO impact reviewed
- [ ] Post‑release monitoring enabled

## Agent Prompts
- Planner: create release plan + milestones
- Critic: review risks + rollback
- Writer: draft release notes
