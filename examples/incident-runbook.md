# Example: Incident Runbook

**Goal:** Standardise response for Sev‑1 outages.

## Output Runbook
1. Identify scope + impact
2. Declare incident + create channel
3. Assign IC / Comms / Ops
4. Mitigate + restore service
5. Post‑incident review

## Agent Prompts
- Surveyor: collect logs + metrics
- Coder: apply mitigation steps
- Writer: generate post‑mortem draft
